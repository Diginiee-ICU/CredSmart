# CredSmart Minimal & Fast-Access Design System (Master Standard)
Source: .agents/skills/credsmart-minimal-design-system/SKILL.md

Core Methodology:
- 52px command header (md:h-13), 28px brand mark, left org switcher, center Command Palette (⌘K) on md: screens.
- Neutral surface architecture (#F8FAFC light / #090D16 dark), Royal Blue (#2563EB) accent, semantic status badges.
- Proportional button sizing (34px standard, 28px table/small, 46px center mobile CTA; zero oversized bloated bubble buttons).
- Screen-fitted viewport containment: bounded scrollable areas, fixed headers and bottom action bars; zero long scrollable pages on desktop.
- Monochromatic hotkey ribbon, split POS workbench (Region 1 fixed top net payable, Region 2 scrollable items/breakdown, Region 3 fixed bottom action dock with F6/F7/WhatsApp).
- Complete deprecation of 3D tilt perspective, rotateX, glowing halos, and floating watermarks.
