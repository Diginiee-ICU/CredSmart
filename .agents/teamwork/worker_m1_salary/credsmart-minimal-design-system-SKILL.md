# CredSmart Minimal & Fast-Access Design System (Master Standard)
Referenced from `.agents/skills/credsmart-minimal-design-system/SKILL.md`.

## Core Guidelines
- Standard Action Button: `h-8.5 px-3 rounded-lg text-xs font-semibold shadow-2xs`
- Small / Table Action Button: `h-7 px-2.5 rounded-md text-[11px] font-medium`
- Micro / Inline Icon Button: `w-7.5 h-7.5` or `w-8.5 h-8.5 rounded-md`
- No sub-11px fonts (`text-[11px]` minimum).
- Monospace Tabular Figures: `font-mono tabular-nums` for currency (₹) and numbers.
- Royal Blue accent: `#2563EB` / `bg-blue-600 hover:bg-blue-700`.
- Hairline borders: `border-slate-200/80` (light) / `border-slate-800` (dark).
- 100% desktop/mobile divergence: `hidden md:block` for desktop, `block md:hidden` for mobile.
- Zero modifications to 19 protected invoice quarantine files.
